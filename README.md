Eye Detection Music Player 🎵👀
An innovative Android application that uses eye-tracking technology to control video playback. The app automatically plays the video when eyes are detected and pauses it when eyes are closed, creating a hands-free experience.

📌 Features
✅ Eye-Tracking Video Control - Automatically plays/pauses video based on eye detection.
✅ Hands-Free Interaction - No need to touch the screen for media control.
✅ Real-Time Status Display - Shows "Eye Detected" or "Eye Not Detected" based on user interaction.
✅ Smooth Video Playback - Uses LookAtMe for eye tracking and Android VideoView for video playback.
✅ User-Friendly Interface - Simple and minimal UI.

🛠️ Technologies Used
Java - Core Android development language.
Android Studio - Development environment.
LookAtMe Library - Handles eye detection.
Android VideoView - For video playback.
XML (UI Design) - Used for frontend development.
